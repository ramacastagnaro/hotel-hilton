# Instrucciones de Instalación para el Panel de Administración

## Dependencias necesarias

Ejecuta este comando en la carpeta `hotel-web`:

```bash
npm install chart.js react-chartjs-2
```

## Estas librerías se usarán para:
- **chart.js**: Librería base para crear gráficos
- **react-chartjs-2**: Wrapper de React para Chart.js

## Compatible con React 19.1.1
Estas versiones son compatibles con tu versión actual de React.
